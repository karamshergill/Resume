SVG Animation

A Breezy Study Desk

About This Project

This project is based on a simple study desk with a table fan, books, an open notebook, a coffee cup, and a small plant.

The idea is to show how a small desk fan creates movement in everyday objects. The fan rotates, the notebook pages move, and the plant leaves shake gently.

The Study Desk

Animation Techniques

This project uses SVG shapes and CSS animations to create movement.

  • Rotation for the table fan.
  • Movement for the airflow paths.
  • Gentle movement for the notebook pages.
  • Opacity changes for the coffee steam.
  • Small rotations for the plant leaves.
